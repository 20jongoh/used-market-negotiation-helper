# 중고거래 협상 도우미

판매자가 하나의 판매 상황을 입력하고 첫 답변, 재협상, 거래 조건까지 결정하도록 돕는 정적 웹서비스입니다. 실제 중고 시세나 거래 성사 확률을 조회·예측하지 않습니다.

## 사용자 흐름

1. 가격 3개, 상태, 등록 기간, 판매 급함, 문의량과 거래 조건을 입력합니다.
2. 제안 비율·차액·할인율과 상황별 이유를 읽습니다.
3. 추천 1차 역제안, 가격 방어, 빠른 판매 후보 중 우선순위를 선택합니다.
4. 실제 판매자 역제안과 구매자 재제안을 입력해 여러 회차의 진전을 비교합니다.
5. 두 거래의 날짜·방식·판매자 부담 비용을 비교합니다.
6. 선택한 가격을 반영한 네 가지 스타일의 답변을 복사합니다.

입력을 바꾸면 이전 결과를 숨기고 다시 분석하도록 안내합니다. 재협상 후 전략을 바꾸면 기존 기록·답변 가격은 유지하고 다음 회차부터 반영합니다. 내부 기준 금액과 조정 가능 폭은 결과에 별도 항목으로 표시하지 않습니다. 구매자에게는 답변 문구만 복사해 전달하도록 안내합니다.

## 구조와 개인정보

- HTML, CSS, 순수 JavaScript. 빌드·프레임워크·런타임 패키지 없음.
- 서버·DB·외부 분석 API·AI·로그인 없음.
- 입력값 및 재협상 기록은 현재 페이지 메모리에서만 처리합니다.
- 입력값을 네트워크 요청, URL, 쿠키, localStorage, sessionStorage, IndexedDB에 넣지 않습니다.
- 폼의 입력 컨트롤에 name을 두지 않아 JavaScript 미작동 시에도 입력값이 기본 폼 제출로 직렬화되지 않습니다.
- 기존 Google AdSense 스크립트는 변경 없이 유지합니다. 광고 스크립트의 네트워크 동작과 도구의 입력값 처리를 개인정보처리방침에서 구분합니다.

## 로컬 실행과 검증

`index.html`을 바로 열거나 정적 파일 서버로 실행합니다. 클립보드는 HTTPS 또는 localhost 환경에서 동작하며 실패 시 직접 복사 안내를 제공합니다.

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

정적 감사에는 Python 표준 라이브러리만 필요합니다.

```powershell
python tests/audit.py
```

전체 테스트는 개발용 Playwright를 제외 폴더에 설치하고, 설치된 Windows Chrome으로 실행합니다. 테스트 자체에서 임시 localhost 정적 서버를 열고 종료하며 외부 요청은 차단합니다. 서비스 배포에는 테스트 패키지가 필요하지 않습니다.

```powershell
python -m pip install --target .test-tools playwright
python tests/test_site.py
```

검증 범위: 요청된 정상·오류 사례, 가격 범위와 전략 순서 4,000개 조합을 포함한 엔진 검사, 다회차 재협상, 답변·전략 연결, 클립보드 성공·실패, 비용 비교, 입력 변경 후 오래된 결과 숨김, 새로고침 초기화, HTML 삽입 방지, 입력 중 네트워크 요청·브라우저 저장 없음. 6개 페이지를 320·375·390·768·1280px에서 검사합니다. 보고서와 화면 캡처는 Git에서 제외한 `.qa/`에 생성합니다.
