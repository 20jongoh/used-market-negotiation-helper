# 중고거래 협상 도우미

판매자가 입력한 조건을 바탕으로 가격 협상 전략, 역제안 가격, 구매자 답변 문구를 계산하는 정적 웹서비스입니다. 실제 중고 시세나 적정 가격을 제공하지 않는 참고용 도구입니다.

## 기능

- 판매가 대비 구매자 제안 비율 분석
- 상품 상태·등록 기간·판매 급함 기반 협상 여유 분석
- 최저 희망 가격을 결과에 공개하지 않는 역제안 계산
- 복사 가능한 구매자 답변과 재협상 대응 문구
- 모바일 반응형 UI, 접근성 기본 지원, SEO 메타데이터
- 서버, API, 데이터베이스, 로그인, localStorage 없이 브라우저 내 계산

## 기술 스택

HTML, CSS, 순수 JavaScript. 빌드 과정이나 외부 프레임워크가 필요 없습니다.

## 로컬 실행

`index.html`을 브라우저에서 열면 됩니다. 일부 브라우저의 클립보드 기능까지 동일하게 확인하려면 정적 파일 서버(예: VS Code Live Server)를 사용하세요.

## 협상 계산 규칙

- 제안 비율: 구매자 제안 ÷ 판매 가격 × 100. 95% 이상부터 70% 미만까지 6단계의 서비스 내부 분석 기준으로 표시합니다.
- 협상 여유: 기본 50점에 상태(-20~+20), 등록 기간(-15~+15), 판매 급함(-20~+20)을 더하고 0~100으로 제한합니다.
- 역제안: `최저 희망 가격 + (판매 가격 - 최저 희망 가격) × 급함 계수`를 사용합니다. 계수는 전혀 급하지 않음 0.7, 조금 빨리 0.6, 적당히 빨리 0.5, 최대한 빨리 0.25이며 1,000원 단위로 반올림합니다. 결과는 구매자 제안보다 낮지 않고 판매가를 넘지 않도록 보정됩니다.
