01 / 판매 상황

지금 어떤 제안을 받았나요?

상품명 외의 기본 항목을 입력해 주세요. 선택한 판매 상황이 추천 가격에 반영됩니다.

연락처나 주소는 입력하지 마세요.

금액은 1원~10억 원의 정수로 입력해 주세요. 쉼표도 사용할 수 있습니다.

결과와 답변에 내부 기준 금액을 별도로 표시하지 않습니다. 구매자에게는 답변 문구만 복사해 보내세요.

    03 / 전략 선택

    어떤 쪽이 더 중요한가요?

    추천은 출발점입니다. 전략을 선택하면 답변 가격과 다음 협상 기준에 연결됩니다.

    기다릴 수 있다면

    가격 방어 전략

    장점
    첫 양보를 줄이고 추가 문의를 비교할 수 있습니다.
    부담
    현재 구매자가 떠나거나 판매 기간이 길어질 수 있습니다.
    잘 맞는 상황
    판매가 급하지 않거나 구체적인 다른 문의가 있을 때.
    일정을 앞당기고 싶다면

    빠른 판매 전략

    장점
    가격 차이를 줄이며 가까운 거래 일정을 제안할 수 있습니다.
    부담
    받는 금액이 줄어듭니다. 낮춘 가격이 거래 성사를 보장하지는 않습니다.
    잘 맞는 상황
    판매 기한이 가깝고 실제로 빠른 거래가 가능한 구매자일 때.

    04 / 다음 대화

    구매자가 다시 제안했나요?

    실제로 보낸 가격과 새 제안을 입력하세요. 계산할 때마다 같은 판매 상황에서 협상 흐름을 이어갑니다.

    다음 답변 가격 후보

    후보를 답변에 반영했습니다. 다음 대화에서 다른 가격을 보냈다면 위의 ‘내가 제안한 가격’을 수정하세요.

    이번 재협상 후보의 기준

      기록은 이 화면에서만 유지됩니다. 새 분석이나 새로고침을 하면 사라집니다.

      05 / 가격 밖의 조건

      더 받기와 더 빨리 팔기, 비교해 보세요

      두 후보를 직접 수정할 수 있습니다. 기본 예시는 빠른 판매와 가격 방어 가격이며, 실제 약속을 뜻하지 않습니다.

      A 조건
      B 조건

      오늘은 0일. 배송비·교통비 등 내가 부담할 비용을 합쳐 입력하세요. 비용을 모르면 0원으로 비교한 뒤 확정 전에 다시 확인하세요.

      시간의 가치를 임의로 돈으로 환산하거나 거래 성공 확률을 가정하지 않습니다. 비용 차감 후 금액을 같은 내부 기준과 비교합니다.

      06 / 실제 답변

      선택한 가격을 대화로 옮기세요

      말투만 바뀝니다. 가격은 선택한 전략 또는 마지막 재협상 후보를 따릅니다.

      거래 시간이나 장소를 확정하지 않은 문구입니다. 보내기 전에 실제 조건에 맞게 확인해 주세요.
