입력 정보 처리

상품명, 판매 가격, 구매자 제안, 최저 희망 가격, 상품 상태, 등록 기간, 판매 급함, 문의 정도, 거래 방식과 재협상·거래 조건 입력은 사용자의 브라우저에서 규칙 기반으로 처리합니다. 서비스의 계산 코드가 이를 서버나 외부 API로 전송하지 않으며 데이터베이스에 저장하지 않습니다.

화면 내 기록과 저장 기능

회원가입과 로그인 기능이 없습니다. 입력값과 재협상 기록은 현재 페이지의 메모리에서만 사용하며 localStorage, sessionStorage, IndexedDB나 쿠키에 저장하지 않습니다. 새 분석은 기존 재협상 기록을 초기화하고 새로고침하면 입력과 기록이 사라집니다. 서비스는 브라우저 자체의 자동 완성·방문 기록 기능을 운영하지 않습니다.

주소와 답변 복사

사용자 입력값을 페이지 주소나 공유 링크에 넣지 않습니다. 사례 불러오기 링크에는 미리 준비한 가상 사례 번호만 들어갑니다. 사용자가 ‘답변 복사’를 누르면 선택한 답변 문구만 기기의 클립보드에 복사합니다. 답변에는 상품명과 선택한 제안 가격이 들어가므로 외부 대화에 붙여넣기 전에 확인하세요. 내부 기준 금액은 별도 항목으로 복사하지 않습니다.

광고 관련 기술

사이트에는 Google AdSense의 광고 관련 스크립트가 설치되어 있습니다. Google의 심사·광고 서비스 제공 과정에서 광고 기술과 별도의 네트워크 요청이 사용될 수 있습니다. 현재 광고 게재 승인은 완료되지 않았습니다.

브라우저 내 계산과 광고 스크립트는 구분됩니다. 서비스는 사용자 입력값을 광고 데이터로 연동하거나 분석 이벤트로 전송하는 코드를 두지 않습니다. 페이지를 불러오면서 필요한 정적 파일과 광고 스크립트의 네트워크 요청은 입력값을 외부 API에 보내 분석하는 기능과 다릅니다.
